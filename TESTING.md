# Testing Guide

## How to Run
From the project root:

```bash
cd codebase
npm test
npm run build
```

## PRD Must-Have Coverage
- Task Management: `src/tests/tasks.test.tsx`
- Goal Setting: `src/tests/goals.test.tsx`
- Calendar View: `src/tests/calendar.test.tsx`
- Progress Tracking: `src/tests/progress.test.tsx`
