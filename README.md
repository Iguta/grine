# Grine

Grine is a personal goal and task tracker web app designed to enhance productivity with a modern and beautiful UI/UX. It supports task management with priorities, goal setting across time horizons, calendar-based task views, and progress tracking dashboards. The UI is responsive, minimal, and polished with a default dark theme and soft accent colors.

## Key Features
- Task management with descriptions, due dates, priority weights, editing, deletion, and prioritization
- Goal setting for yearly resolutions, monthly goals, and daily goals with customizable themes/categories
- Calendar view of tasks with day-level expansion and management
- Progress tracking dashboards for today, this week, this month, and this year
- Modern, minimal, responsive UI with dark theme and subtle animations

## Tech Stack
- React + TypeScript
- Vite

## Getting Started
```bash
cd codebase
npm install
npm run dev
```
